# snippet-generator

[Snippet generator](https://snippet-generator.app/) is a tiny React app to help you create [Visual Studio Code](https://code.visualstudio.com/), [Sublime Text](https://www.sublimetext.com/), [Pulsar](https://pulsar-edit.dev/) (formerly Atom) and [Zed](https://zed.dev/) snippets. If you like the project, [buy me a coffee](https://www.buymeacoffee.com/pawelgrzybek), please.

Enjoy!
